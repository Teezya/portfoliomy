# DANIL.DEV — Developer Portfolio

A responsive bilingual portfolio built with plain HTML, CSS and JavaScript. Includes scroll-reveal animations, a mobile navigation menu, language switcher, project cards and generated project concept visuals.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Project visuals
The images in `assets/` are generated presentation concepts based on the project descriptions. They are not screenshots of deployed applications. Replace them with actual screenshots when available.

## Deploy
- **Vercel:** import this folder/repository; use the static site preset and `.` as the output directory.
- **Netlify:** drag and drop the folder into Netlify Drop, or connect the GitHub repository with publish directory `.`.
- **GitHub Pages:** push the files to a repository and enable Pages from the `main` branch, root folder.

## Before publishing
- Confirm that the email and phone number should be public.
- Check the project links and descriptions.
- Replace concept images with real screenshots when you have them.
